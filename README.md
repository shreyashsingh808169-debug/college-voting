# College Voting Project

This version intentionally uses a simple JSON file database, so it does NOT require SQLite, Visual Studio, C++ build tools, or Python.

## Windows run steps

Open CMD inside this folder:

    cd /d D:\college-voting
    npm install
    npm start

Then open:

    http://localhost:3000

Admin demo password:

    change-me

Votes are saved in `data.json`.

For a classroom/demo project only. For real institutional use, add proper authentication, HTTPS, secure password hashing, backups, and an appropriate production database.
